# ねこの買い物メモ プライバシーポリシー

最終更新日：2026年9月15日

「ねこの買い物メモ」（以下「本アプリ」）は、ユーザーのプライバシーを尊重します。

## 1. 収集する情報

本アプリは、氏名、メールアドレス、位置情報などの個人情報を収集しません。

## 2. 買い物メモの保存

ユーザーが入力した商品名などの買い物メモは、ユーザーの端末内にのみ保存されます。

これらのデータを開発者のサーバーへ送信することはありません。

## 3. アカウント

本アプリには、アカウント登録およびログイン機能はありません。

## 4. 広告・アクセス解析

本アプリは、広告サービスおよびアクセス解析サービスを使用していません。

## 5. 第三者への提供

本アプリは、ユーザーが入力したデータを第三者へ提供しません。

## 6. データの削除

本アプリに保存されたデータは、アプリ内の削除機能によって削除できます。

また、本アプリを端末からアンインストールすることで、本アプリが端末内に保存したデータは削除されます。

## 7. プライバシーポリシーの変更

本アプリの機能変更などに伴い、本プライバシーポリシーを変更する場合があります。
